# Project Brief

## Product

Recommended Packs is a backend service for a beauty ecommerce recommendation engine.

## Backend Goal

Provide a clean NestJS foundation that can later support beauty product data, customer preferences, recommendation workflows, and ecommerce integrations.

## Current Scope

The current implementation is foundation only:

- NestJS application structure
- TypeScript setup
- Prisma setup for PostgreSQL
- Global request validation
- Swagger API documentation
- Backend contribution rules and roadmap

## Explicitly Out of Scope For Now

- Recommendation logic
- Product catalog models
- Customer profile models
- Orders
- Payments
- Admin CRUD
- Frontend

## Core Technical Stack

- NestJS
- TypeScript
- Prisma
- PostgreSQL
- class-validator
- class-transformer
- Swagger
